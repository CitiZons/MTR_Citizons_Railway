# Citizons Railway

[English](README.en.md) | [简体中文](README.zh-CN.md)

A track resource pack for [MTR](https://github.com/Minecraft-Transit-Railway/Minecraft-Transit-Railway), targeting Minecraft **1.20.1**, Forge **47.4.18** and MTR **4.0.3**. The current pack version is **0.1.3**, paired with [MTR Railway Point Advanced](https://github.com/CitiZons/MTR_Railway_Point_Advanced) **0.1.7**.

## Installation

1. Put [Citizons_Railway-0.1.3.zip](dist/Citizons_Railway-0.1.3.zip) in the instance `resourcepacks` folder and enable it. You may also use the folder `resourcepacks/Citizons_Railway-0.1.3`. The compatible file [dist/Citizons_Railway.zip](dist/Citizons_Railway.zip) has the same contents.
2. Install the same Point Advanced 0.1.7 build on both client and server and remove older JARs.
3. Select one of the track styles listed below in MTR. If a turnout was manually locked to another style, set it back to automatic or to the matching Citizons style in the blueprint.

## Track styles

| MTR style | Structure |
|---|---|
| Citizons high-fidelity rail, ballast, 1435 mm | Recessed central concrete sleepers, clip fasteners and arched trapezoidal ballast bed. |
| Citizons high-fidelity rail (outer guard), ballast, 1435 mm | Two inner guard rails with shared reinforced seats; the ends taper inward toward the centre. |
| Citizons high-fidelity rail (central guard), ballast, 1435 mm | Flat-top sleepers, a central guard rail, independent bolt plates and protected ends. |
| Citizons high-fidelity rail, slab with sleepers, 1435 mm | Continuous concrete slab and separate shoulder support blocks. |
| Citizons high-fidelity rail, direct support without sleepers, 1435 mm | Two continuous longitudinal concrete supports without a horizontal central slab. |

The gauge is **1.435 m**, rail-top height is **0.26428 m**, and the repeating unit is **0.6 m**. Maximum ballast thickness is **0.35 m**; the sleeper slab is 0.35 m thick, while the direct-support concrete strips are thickened to the same track-bed base. Rail sections and fasteners are shared by all styles.

Turnouts, slide plates, frogs, guard-rail seats and end transitions are generated by Point Advanced. In 0.1.7, all three bed types share the same fastener layout. At the V nose, only inner fasteners are omitted; outer guard-side fasteners remain, and matching gaps up to 2 cm in rail, guard-rail, ballast and concrete-bed joints are filled. With only this resource pack installed, MTR displays its resource models and does not provide these procedural features.

## Detail levels

Point Advanced switches between high, medium and low detail at **4 m / 12 m** by default; these values can be changed in the mod configuration. Face counts per 0.6 m repeating unit are:

| Style | High | Medium | Low |
|---|---:|---:|---:|
| Ballasted mainline | 2216 | 476 | 288 |
| Ballasted outer guard | 1691 | 476 | 346 |
| Ballasted central guard | 2632 | 600 | 396 |
| Slab with sleepers | 1806 | 395 | 259 |
| Direct support without sleepers | 1720 | 318 | 182 |

When the resource pack is used alone, MTR uses the high-detail model selected by the style entry.

Medium and low detail reduce fastener side walls and undersides, as well as lower bed and sleeper geometry, while retaining rail sections, joint groups and the texture atlas. High-detail models are unchanged. OBJ files share position, UV and normal indices. Point Advanced 0.1.7 caches ordinary rails and supports in complete 8 m chunks and selects LOD per chunk; rotating the camera does not rebuild unchanged geometry.

## Regeneration and packaging

The source directory is `resourcepacks/Citizons_Railway`; `VERSION` is the release-version source, and `pack_format: 15` identifies the Minecraft resource format.

```powershell
python -m pip install numpy Pillow
python generate_citizons_railway.py
python railway_resource_checks/validate.py
python package_release.py
```

Packaging produces a versioned ZIP, a compatibility ZIP and an install-ready folder at `resourcepacks/Citizons_Railway-0.1.3`. Use `railway_resource_checks/render.py` for model previews.

See [MODEL_NOTES.md](resourcepacks/Citizons_Railway/MODEL_NOTES.md) for model dimensions, groups and materials, and [CHANGELOG.md](CHANGELOG.md) for version changes.

This project is primarily implemented with ChatGPT.
